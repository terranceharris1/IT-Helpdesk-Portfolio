## Projects

### 🔐 Password Reset & Account Unlock (ServiceNow)

**Issue:**  
User was unable to log into their workstation due to account lockout.

**Tools Used:**  
- ServiceNow  
- Active Directory (lab environment)

**Steps Taken:**
1. Created incident ticket in ServiceNow  
2. Investigated login issue  
3. Identified account lockout  
4. Reset password and unlocked account  

**Resolution:**  
User successfully logged in after password reset and account unlock.
